# تطبيق المالية v3 — بدون أيام عمل

## الفكرة
- كل وارد/مصروف له **تاريخ عملية** (قابل للتعديل عند الإضافة) + **وقت تسجيل** تلقائي
- لا فتح/غلق يوم ولا رصيد افتتاحي منفصل (أي سيولة تُسجَّل كوارد «أخرى» إن لزم)
- الرئيسية: تراكمي من أول قيد + زر تحديث + صافي يوم محدد
- تعديل/حذف بعد الحفظ: **المالك فقط** مع ملاحظة إلزامية في سجل التدقيق

## التشغيل
```bash
cd backend/Finance.Api
dotnet restore && dotnet run
# http://localhost:5200

cd ../../frontend
npm install && npm run dev
# http://localhost:3002
```

| مستخدم | كلمة المرور |
|--------|-------------|
| owner | Owner@123 |
| finance | Finance@123 |

## المعادلات
- التراكمي: مجموع الواردات − مجموع المصروفات (كل القيود)
- صافي يوم D: وارد(D) − مصروف(D)
- تراكمي قبل D: صافي كل ما OperationDate < D
- توزيع شركاء: (وارد−مصروف الفترة) × النسبة٪ — تنبيه إن المجموع ≠ 100٪
