# تطبيق المالية v2

## التشغيل
```bash
cd backend/Finance.Api
dotnet restore && dotnet run
# http://localhost:5200

cd frontend
npm install && npm run dev
# http://localhost:3002
```

## حسابات
| مستخدم | كلمة المرور | الدور |
|--------|-------------|--------|
| owner | Owner@123 | مالك |
| finance | Finance@123 | مالي |

## إن ظهر خطأ أعمدة بعد التحديث
احذف ملف `finance.db` من مجلد الـ Api ثم أعد `dotnet run` (بيانات تجريبية فقط).

## ما يشمله v2
- صفحات مستقلة: واردات / مصروفات
- فتح يوم تالٍ بعد الإقفال (ليس نفس التاريخ)
- إعادة فتح يوم مقفل للمالك + تدقيق
- شركاء: ظهور بعد الإضافة، تفاصيل، مصروفات مرتبطة، احتساب توزيع، تنبيه نسب ≠ 100%
- موظفون: تاريخ بدء، نشط/موقوف، حذف للمالك
- إعدادات: دور عند الإنشاء، حذف مستخدم، سمات، شعار وخلفيات رفع/حذف
- Toast: ~1.8 ثانية + إغلاق بالضغط
- تاريخ محلي (القاهرة) عند أول فتح

## المعادلات
صافي اليوم = افتتاحي + وارد − مصروف
افتتاحي = صافي اليوم السابق
توزيع الشركاء (زر): (مجموع وارد−مصروف للفترة) × النسبة%
